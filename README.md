# 🛡️ Gus' Custom Filters

Personal cosmetic and network filters. Mostly opinionated stuff that the big lists don't cover — ads and widgets, leftover telemetry, and things that just bother me personally. I use this blocklist with Brave Shields. That said, it should also work on other content blocker that support AdBlock Plus syntax


## Subscribe

Click the link below to add these filters directly to Brave:

[![Subscribe](https://img.shields.io/badge/Brave%20Shields-Subscribe-orange?logo=brave&logoColor=white)](https://subscribe.adblockplus.org/?location=https://raw.githubusercontent.com/guslockhart/ublock/blocklist/1.txt&title=Gus%27%20Custom%20Filters)

Or add the raw URL manually in **brave://settings/shields/filters → Add custom filter lists**:

```
https://raw.githubusercontent.com/guslockhart/ublock/blocklist/1.txt
```

## What's in here?

These filters are a complement to the big lists not a replacement. They cover gaps I've run into personally:
- **Cosmetic filtering** — hiding leftover junk that survives blocking
- **Telemetry & analytics** — anything i don't want phoning home
- **AI slop** — self explanatory 
- **Other annoyances** — cookie banners, newsletter subscription, sticky headers, persistent floating chat button etc etc

- **AdGuard Blocklists**
	- AdGuard DNS Base filter
	- AdGuard Ads filter
	- AdGuard Banners and Widgets filter
	- AdGuard URL Tracking filter
	- AdGuard Social Media filter
	- AdGuard Tracking Protection filter
	- AdGuard Cookie Notices filter
	- AdGuard Popups filter
	- AdGuard Mobile Ads filter
	- AdGuard Mobile Banners and Widgets filter 

- Everything in this list exists to fill gaps those two don't cover — specific domains, cosmetic annoyances, and miscellaneous clutter that slips through.
- This is a **personal** list — things get added and removed based on my own browsing experience.

- I don't accept requests.
